# Code of Conduct

## Our Pledge

We are committed to providing a welcoming and inclusive environment for everyone.

## Our Standards

### Professionalism
- Use respectful language
- Provide constructive feedback
- Acknowledge and learn from mistakes
- Focus on what's best for the project

## Unacceptable Behavior

- Harassment, insults, or demeaning language
- Personal attacks or politics
- Spam or malicious intent
- Sexual or offensive content

## Reporting Issues

If you experience harassment or see a policy violation, email: [security@dataforge-ai.dev]

## Enforcement

We reserve the right to remove content that violates these standards.

## Open Source Etiquette

- Search issues before creating new ones
- Code review respectfully
- Be patient with maintainers
- Follow project conventions

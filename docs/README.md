## Example Outputs

Real-world example outputs generated by DataForge AI:

- [Employee Dataset Analysis](examples/employees/) - Analysis of employee data with visualizations
- [Product Dataset Analysis](examples/products/) - Analysis of product data with visualizations

### Example Contents

Each example includes:
- **report.html** - Interactive HTML report with embedded visualizations
- **report.json** - Structured JSON report with all analysis results
- **visualizations/** - Individual interactive Plotly charts
  - Distribution plots for numeric columns
  - Box plots for outlier detection
  - Bar charts for categorical data
  - Scatter plots for correlation analysis
  - Correlation heatmap
